# Mova Bubble Illustrations

This directory contains the bubble mascot illustrations for Mova, an AI-powered personal fitness management application.

## Purpose

The Mova bubble mascot adds a friendly visual identity to the application. Illustrations may appear during onboarding, workout planning, activity tracking, hydration reminders, recovery, and milestone celebrations.

- `mova-bubble-welcome.png` — Welcome and onboarding
- `mova-bubble-fitness.png` — Workout and fitness activities

- `mova-bubble-focus.png` — Focus and listening
- `mova-bubble-hydration.png` — Hydration

## Usage

These illustrations are intended for use in the Mova React Native application.

The images can be displayed using React Native's `Image` component. Subtle floating, scaling, and entrance animations may be added using React Native's animation APIs.

## Design Guidelines

- Keep illustrations appropriately sized for their intended UI placement.
- Preserve the aspect ratio of each image.
- Avoid overcrowding screens with decorative illustrations.
- Use the mascot where it supports the user's experience.
- Keep animations subtle and provide appropriate reduced-motion behaviour.

## Asset Format

PNG files are intended for direct display in the application. Corresponding SVG files are included for vector editing or compatible SVG workflows.
